iA trajectory is the curve x(t): position along a one-way guideway vs. time — exactly one x for every t. Slope = velocity v = dx/dt: steep → fast, flat → stopped. Curvature = acceleration: concave-down → decelerating, concave-up → accelerating. The car drives up the road beside the position axis, always level with its trajectory point.

iWhen a vehicle reaches the end of the route (x = L) it wraps back to x = 0, so each trajectory becomes a sawtooth — one tooth per lap. Relations: average speed v = L/C (C = cycle time), flow q = n/C, density k = n/L, so q = k·v — the fundamental relation holds on loops too.

iGazis–Herman–Rothery (GM): each follower's acceleration is a delayed response to its leader, a = α·vm/sl·Δv evaluated at t−T (1st: m=0, l=0 · 2nd: two-level α, higher when spacing < 130 ft · 3rd: m=0, l=1 · 4th: m=1, l=1 · 5th: m=1, l=2). Every follower obeys the selected model, so one leader input cascades car-to-car. Press 🛑 mid-run and watch the disturbance propagate back as a shockwave; α, T and free-flow speed apply live. Stability: for the linear model the platoon is asymptotically stable only if α·T ≤ ½ — exceed it and oscillations grow down the platoon until spacings collapse.
